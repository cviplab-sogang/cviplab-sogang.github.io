# CVIP Lab · Sogang University — English Website

A static, English-language version of the CVIP Lab homepage, based on the existing design and verified source information. It is a separate variant and does not change the existing Korean website unless you upload it.

## Deployment on GitHub Pages

Upload `index.html`, `assets/`, `.nojekyll`, and `sitemap.xml` (if present) to the root of the repository. In repository **Settings → Pages**, select **Deploy from a branch → main → /(root)**. The files in this ZIP use relative asset paths.

To test locally, open `index.html` in a browser.

## Editing

- Home, Research, Projects, Papers, People, Contact: `index.html`
- Colors and layout: `assets/css/site.css`
- Interactions and filtering: `assets/js/site.js`
- Images: `assets/images/`

## Source and translation notes

The layout and content structure are derived from CVIP Lab's existing website and the previously supplied research-page PDF. Korean-language publication titles have been translated into English **for display**; they have not been verified as official English titles. Where a paper's official title or author spelling is important, compare the entry against the original proceedings or publisher record before publishing. No research/project items were intentionally omitted in the English conversion.

This version was created as an optional English-language alternative. Do not upload any private lab files to your public GitHub Pages repository.
